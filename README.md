# dopamine-platform

Новая версия платформы dopamine (web + API для лаунчера).

## Запуск

```bash
cd dopamine-platform/web
npm install
copy .env.example .env.local
npm run db:push
npm run dev
```

## Что уже заложено

- авторизация по email/паролю с подтверждением почты;
- вход лаунчера в аккаунт сайта по логину/паролю;
- заготовка друзей, лайков/дизлайков, аватаров, экономики;
- топы: часы, лайки, дизлайки, доступные слоты;
- платежная абстракция `payment_intents` для будущей покупки монет за деньги.
